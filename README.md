# Havok Physics &amp; Animation 2013
This is a distribution dated 2013-03-20 of the **Havok Physics** and **Havok Animation** SDKs, the honorable middleware packages for physics simulation. 
This repository contains the publicly released, legacy Havok interface codes.
It is one of some internal distros owned by the SIGMA Technology Group, it is an archival resource for developers working with legacy Havok-enabled projects. 
This repository currently intentionally contains only C header files (.h).

## Contribution

This repository is being made available in response to requests from modding organizations seeking to preserve Havok-enabled gaming softwares.
